# ELISA 曲线拟合工具

在浏览器中打开即可使用的网页工具，无需安装，可完成 ELISA 标准曲线的四参数 Logistic（4PL）拟合与样本浓度计算。无后端、无数据持久化，所有计算均在客户端完成。

## 主要功能

- **4PL 标曲拟合**：`y = d + (a − d) / (1 + (x/c)^b)`，自实现 Levenberg-Marquardt 非线性最小二乘（对数浓度空间拟合，多起点重启取最优），输出参数 a/b/c(EC50)/d、R² 与收敛状态
  - 约定 b > 0、c > 0，曲线方向由 a 与 d 的大小关系决定（a > d 降低，a < d 升高）
  - 未收敛的拟合（达到最大迭代 / 矩阵奇异 / 无改善）会明确报错，不用于浓度计算
  - 要求至少 5 个**不同的正浓度**标准品水平（浓度 > 0，零浓度空白不参与拟合），复孔不计入；标准品 OD 必须存在响应变化，平坦数据会被拒绝
  - 标准品数据一旦修改，旧拟合立即失效并提示重新拟合
  - EC50 相对标准品范围的位置诊断（范围内 / 范围外 / 严重偏离），辅助判断曲线可用性
- **标准品回算**：自动回算各标准点浓度并给出回收率（期望 80%–120%）；启用空白校正时，实测与拟合 OD 均按原始读数口径展示
- **样本浓度计算**，两种录入模式：
  - **96 孔板模式**：8×12（A–H × 1–12）孔位录入，格内直接输入，可在 分组 / OD / 稀释倍数 三种录入模式间切换（默认 OD），OD / 稀释倍数模式用方向键跨孔；分组模式的方向键移动文字光标；三种模式均用 Enter 下移，到底部转入下一列；上下双板（孔位录入板 + 浓度结果板）横向滚动同步；结果一键复制（只复制浓度 / 复制分组+浓度，制表符分隔，可直接粘贴到 Excel）
  - **OD 浓度映射模式**：逐行录入样本名 / OD / 稀释倍数
- **样本状态标识**：有效 / 低于标准曲线范围 / 高于标准曲线范围 / 无法计算 / 稀释倍数无效，超出范围不展示外推浓度
- **空白孔校正**：启用时必须恰有一条有效的零浓度标准品行，其 OD 从参与计算的 OD 中减去；关闭时可无空白行，但仍不允许多条零浓度行
- **标准曲线可视化**：对数浓度轴，拟合曲线、标准品散点、来自 OD 浓度映射表的未知样本点、标准曲线范围与 EC50 参考线

页面首次打开为标准品空表，点击「载入示例」可填入示例数据体验完整流程。

## 界面风格

孔板行字母标识使用透明底色，与所在区域的页面底色自然衔接；输入板和浓度结果板遵循同一规则。

采用暖米白、浅灰与赤陶色，衬线标题与系统无衬线正文保持统一层级，图表与状态提示保留必要的颜色区别。

页眉内容区居中，品牌与标题靠左，操作靠右；页眉位于文档顶部，随页面正常滚走，窄屏允许换行。页眉背景与分隔线铺满页面宽度。

孔板输入、行列标记和结果热图对齐，四档浓度保持不同明度，拟合图包含可读的对数刻度。

## 数据与隐私

应用不发送网络请求、不存储用户数据，无认证逻辑，无环境变量 / 密钥。所有数据只停留在当前浏览器会话中。

## 本地运行

对外版本以 GitHub Release 为准；应用版本来自 `package.json`，发布时与 Release tag 同步。 `package-lock.json` 中的根应用版本同步更新。

推荐 Node.js 22（至少 22.12）或 24 及以上版本；也支持 Node.js 20（至少 20.19）。具体范围与 package.json 的 `engines` 一致。

```bash
npm ci          # 按锁文件安装依赖
npm run dev     # 开发服务器（http://localhost:3000，支持 HMR）
npm run build   # 生产构建（先 tsc -b 类型检查，再 vite build 输出到 dist/）
npm run preview # 预览生产构建
npm run lint    # ESLint 检查
npm run test    # Vitest 单元测试
```

提交代码前请确保 `npm run build`、`npm run lint` 与 `npm run test` 均通过。

## 部署

纯静态站点。`npm run build` 产出 `dist/`，构建资源采用相对路径，页面可放在域名根目录或子目录（如 `/elisa/`），也可直接访问该目录的 `index.html`。静态托管需能提供这些文件；访问目录时保留末尾 `/`，无需额外的页面路由回退配置。
